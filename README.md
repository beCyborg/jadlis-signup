# Агент сам регистрирует тебя на веб-сервисе: свой алиас, пароль в 1Password, письмо подтверждения

Скилл `/signup` для Claude Code заводит аккаунт на новом сервисе. Сначала он спрашивает, какие
данные ввести, и один раз подтверждает их с тобой. Потом создаёт под сервис отдельный алиас
Proton Pass и генерирует пароль прямо в 1Password. Форму заполняет агент browser-operator, а
письмо подтверждения скилл ловит сам. Пароль не попадает в контекст модели.

```
claude plugin marketplace add https://github.com/beCyborg/jadlis-hub.git
claude plugin install jadlis-signup@jadlis
```

## Зачем

Регистрация на новом сервисе отнимает внимание: придумать адрес, придумать пароль, сохранить его,
заполнить форму, дождаться письма, кликнуть ссылку. Скилл делает это сам и держит порядок:

| Проблема | Что делает скилл |
|---|---|
| Один адрес на всех сервисах, спам и утечки | На каждый сервис — свой алиас `<префикс>-<сервис>` в Proton Pass |
| Пароль надо придумать и не потерять | 1Password генерирует пароль на 20 символов и сразу хранит логин |
| Пароль светится в чате или буфере обмена | Браузер берёт пароль через одноразовый локальный адрес, модель его не видит |
| Форма отправилась дважды, два аккаунта | Форма уходит один раз; при сомнении скилл сначала смотрит почту и сайт |
| Письмо подтверждения потерялось | Скилл ждёт письмо, берёт ссылку или код и доводит регистрацию до конца |

## Как выглядит

Ты пишешь: «зарегистрируйся на example.com, бесплатный план». Дальше:

1. Скилл задаёт один вопрос: адрес страницы регистрации, имя для формы, план, способ входа. Ты
   подтверждаешь сводку.
2. Скилл проверяет, нет ли уже аккаунта, и создаёт алиас `agent-example`.
3. 1Password создаёт запись с паролем на 20 символов. Скилл запоминает её id.
4. Агент browser-operator заполняет форму в своём профиле Chrome и отправляет её один раз.
5. Скилл ждёт письмо на алиас, открывает ссылку подтверждения или вводит код.
6. Скилл проверяет, что аккаунт работает, ставит в записи 1Password отметку `verified` с датой и
   присылает отчёт: сервис, алиас, id записи. Пароля в отчёте нет.

Оплату, привязку карты, SMS, CAPTCHA, которую агент не проходит, и вход через Google или GitHub
делаешь ты. Скилл оставляет нужную страницу открытой и ждёт.

## Как поставить

Нужен Claude Code на macOS и три плагина-зависимости. Claude Code ставит их вместе со скиллом:

| Плагин | Что даёт |
|---|---|
| `jadlis-secrets` | `op-agent.sh`, `secret-relay.py`, `proton-alias.sh` и образец `agent.conf.example` |
| `jadlis-mail` | `mail-wait.sh` и `jm` поверх himalaya: ждать письмо и читать его |
| `jadlis-browser` | шаблон агента `browser-operator` и `agent-chrome.sh` для своего профиля Chrome |

Ещё нужны свои аккаунты и программы:

- аккаунт Proton Pass и `pass-cli`;
- сервисный аккаунт 1Password с правом записи в отдельный сейф и `op`;
- ящик, куда приходят письма алиасов, подключённый к `jm` (для Proton — через Proton Mail Bridge);
- `jq` и `python3`.

Шаги установки:

1. Поставь плагин командами выше. Если зависимости не встали сами, поставь их так же:
   `claude plugin install jadlis-secrets@jadlis` и так далее.
2. Выполни шаг установки каждой зависимости из её README: скрипты копируются в
   `~/.claude/scripts/`, агент `browser-operator` — в `~/.claude/agents/`.
3. Скопируй `agent.conf.example` из jadlis-secrets в `~/.config/jadlis/agent.conf` и заполни.
4. Проверь готовность:

```
bash "${CLAUDE_CONFIG_DIR:-$HOME/.claude}"/plugins/cache/jadlis/jadlis-signup/*/scripts/preflight.sh
```

Или попроси Claude: «/jadlis-signup:signup проверь готовность». Скрипт не ходит в сеть и не
читает секреты. Он печатает список проверок и отмечает, чего не хватает. Код выхода 1 значит, что
что-то не готово.

Скилл читает из `agent.conf` такие ключи:

| Ключ | Зачем | Если пусто |
|---|---|---|
| `OP_VAULT` | сейф 1Password для новых логинов | обязателен |
| `ALIAS_PREFIX` | алиас `<ALIAS_PREFIX>-<сервис>` | обязателен |
| `BROWSER_PROFILE` | профиль Chrome для browser-operator | обязателен |
| `MAIL_ACCOUNT` | аккаунт `jm`, куда приходят письма алиасов | аккаунт `jm` по умолчанию |
| `MAIL_FOLDER` | папка, где ждать письмо | `All Mail` |
| `SIGNUP_NAME` | имя для формы | скилл спросит |
| `ALLOW_OAUTH` | `yes` разрешает агенту вход через Google или GitHub | вход через OAuth делаешь ты |

Удалить: `claude plugin uninstall jadlis-signup@jadlis`.

## Как пользоваться

Набери в Claude Code:

```
/jadlis-signup:signup зарегистрируйся на example.com
```

Или скажи своими словами: «заведи аккаунт на …», «нужен аккаунт в …», «регистрация на сервисе …».
Скилл задаст один вопрос и подтвердит сводку. Дальше он работает сам и останавливается только на
твоих шагах.

Если аккаунт на этом сервисе уже есть в 1Password или алиас уже создан, скилл скажет об этом и
возьмёт существующие. Второй аккаунт он не заводит.

## Границы и стоимость

**Чего не делает.** Не платит, не вводит карту, не проходит SMS-подтверждение и не входит через
OAuth без разрешения в `agent.conf`. Не отправляет форму второй раз: при сбое он сначала проверяет
почту и сайт. Почту не разбирает — это jadlis-mail. Существующие пароли не ищет — это
jadlis-secrets.

**Что тратит.** Одна регистрация — это несколько вызовов Bash и один агент browser-operator. Агент
тратит основную часть токенов из квоты Claude Code. Денег сверх подписок Claude Code, 1Password
и Proton скилл не требует.

**Проверено:** синтаксис `preflight.sh` в bash и zsh, прогон preflight на Mac, `claude plugin
validate --strict`. Живую регистрацию этой версией не запускали: процесс перенесён из рабочего
скилла, который регистрировал аккаунты на сервисах. На других машинах не проверял — если не
встало, напиши в issue.
